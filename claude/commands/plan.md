# /plan

- 目的は、原因調査と実行計画の作成に限定する
- 実装・設定変更・不要な横展開はしない
- まず対象範囲で事実確認し、見つけた根拠を短く整理する
- 出力は原則 3 ステップ以内の計画にする
- 追加確認が必要な場合だけ、作業継続に必要な 1 問を短く聞く
- 詳細な品質手順や TDD は持ち込まない
